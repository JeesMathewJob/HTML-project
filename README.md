# VoteSphere – Role-Based Online Polling and Voting System
CSE326 web development project (Team Ignite) – HTML5, CSS3 and vanilla JavaScript only.

## Run
Open the folder in VS Code, right-click `index.html` -> **Open with Live Server**
(or simply double-click `index.html`).

## Demo accounts (password: `demo123`)
| Role | Email |
|------|-------|
| Admin | admin@votesphere.demo |
| Poll Creator | creator@votesphere.demo |
| Voter | voter@votesphere.demo |

## Deploy on GitHub Pages
Push the folder to a repository -> Settings -> Pages -> Deploy from branch `main` / root.

## Security note
Data is stored in the browser (localStorage / sessionStorage). This is a college prototype and
is **not** secure enough for real elections.
